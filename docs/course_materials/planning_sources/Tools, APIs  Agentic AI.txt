=== PAGE 13 ===
Project: Add a Tool
Milestone: at least one meaningful tool or action in your application.
1. Find the need: a question in your test set that documents cannot answer (live data, a
calculation, an action).
2. Choose: a custom function (start from the ECB notebook), or a provider tool (search,
code) if a test question needs one.
3. Describe it: purpose, inputs, outputs, limits.
4. Test: called when needed? Not called when not? Failures handled?
Meaningful means a capability your application needs: enabling search or code is not, by
itself, an improvement. Programming is not a prerequisite: an LLM can draft the function;
you must understand what it does.
