# 课程资料与历史报告

当前运行、测试和源码提交入口见项目根目录 [README](../../README.md)。本目录只保留独有课程材料与可能仍需使用的报告，不含可切换运行的旧版本。

- `planning_sources/`：旧项目中发现的课件文字、作业要求截图、组员方案与讨论等原始资料，按原内容保留。`Wearable_Project_原版备份.txt` 与同名现行资料内容不同，保留供作者判断。
- `teacher_requirements.md`：教师要求原文摘录。
- `technical_report_draft.md`、`evaluation_report_draft.md`：既有报告草稿，包含待填项及旧版本描述，作者归属与提交状态无法确认，未改写正文。
- `COURSE_REQUIREMENTS_REVIEW.zh-CN.md`、`evaluation_plan.md`：既有课程要求核对与评估方案，作为课程材料保留，其版本、路径和实施状态描述属于当时记录。
- `REDTEAM_CHECKLIST_EN.md`、`DATA_NOTES.md`、`TEST_RECORDS.csv`：旧课堂包内的独有组员测试清单、数据说明及空记录表。是否仍用于作业无法确认，保留原文；其中旧版本标识和权限说明不代表当前入口或功能。
- `evaluation/REPORT_EVALUATION_FINAL.md`：既有历史评测定稿；`REPORT_EVALUATION_REVIEWED.md`、`REPORT_EVALUATION_SECTION.txt` 是保留的报告其他稿件，作者归属与实际提交用途无法确认。
- `evaluation/` 的题目、评分表、协议、测试XML、版本清单、三个实际模型批次的证据及既有公网验收：仅支持历史报告，不是当前测试成绩。未重跑、未回写评分。报告内依赖文件已随报告保留；旧源码链接转成历史路径文字，旧运行快照已删除。

历史报告的13条会话证据已去掉重复的 `system_prompt` 等指令正文，保留实际回答、工具证据、校验信息和版本元数据；每条附原文件哈希与删减字段说明。它们是证据节选，不能再按历史清单验证为完整原始文件，也不能用来恢复旧运行版本。原版本清单仅保留作为历史报告依据。

本次将这些材料从旧副本移出，以免删除独有原始资料或用户报告。其余旧运行包、逐次测试临时目录、开发中间分析和重复压缩包已经清理。历史报告不能证明当前版本的模型质量、公开服务状态或临床效果。当前改进证据见 [improvement_examples.md](../improvement_examples.md)。

待作者确认的材料集中为：两份报告草稿、`REPORT_EVALUATION_REVIEWED.md` 与 `REPORT_EVALUATION_SECTION.txt` 的提交用途、三份旧课堂测试材料，以及 `planning_sources/` 中旧组方案、讨论、`starter.txt` 和原版备份的后续用途。未因版本旧或名称含“备份”删除这些独有内容。
